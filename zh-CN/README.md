# 配方浏览器（RecipeBrowser）

在游戏内查询合成配方、物品图鉴和怪物图鉴，界面复刻 tModLoader 版 Recipe Browser。

## 功能

- **配方**页：按名称 / 工具提示搜索，勾选自己有的制作站，按分类、排序、筛选浏览；底部列出所需的制作站与材料，右侧列出该物品的掉落来源
- **制作**页：查看某个物品是怎么来的——合成配方、掉落、采集都会列出来
- **物品**页：浏览全部物品，同样带分类 / 排序 / 筛选
- **怪物图鉴**页：浏览怪物及其掉落物
- 点中一条配方时，游戏自带的制作菜单会同步跳到这一条
- 窗口可拖动、可缩放，位置和尺寸自动保存
- 默认用鼠标中键查询悬停或手持的物品，按键可在 F6 → 快捷键里修改
