# Recipe Browser (RecipeBrowser)

Look up crafting recipes, the item catalogue and the bestiary in game.
The interface is a port of the tModLoader "Recipe Browser" mod.

## Features

- **Recipes** tab: search by name or tooltip, tick the crafting stations you have, browse by category / sort / filter;
  the bottom bar lists the required stations and ingredients, and the right column lists where the item drops from
- **Craft** tab: see how an item is obtained - recipes, drops and gathering are all listed
- **Items** tab: browse every item, with the same category / sort / filter bar
- **Bestiary** tab: browse enemies and their drops
- Picking a recipe also jumps the game's own crafting menu to it
- The window can be dragged and resized; position and size are saved automatically
- Middle mouse button queries the hovered or held item by default, rebindable in F6 -> Keybinds
